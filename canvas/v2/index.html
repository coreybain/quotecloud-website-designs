One page. Two ways to build it.

Follow one proposal from freeform design on a canvas to structured rows and columns.

  1. 01 Canvas Mode

    Start on a blank canvas

    Canvas Mode works like a visual design tool, much like Canva or PowerPoint. Pick the page size and orientation, show the grid and turn on snapping.

  2. 02 Canvas Mode

    Place blocks anywhere

    Drop text, images, price tables, QR codes and signatures exactly where you want them, free of a traditional document flow.

  3. 03 Canvas Mode

    Drag, resize and snap

    Pull a photo into place and resize it freely. Alignment guides and snap to grid keep every edge precise.

  4. 04 Canvas Mode

    Rotate and layer

    Tilt the price card and bring it forward over the photo. Layered layouts that read like a designed brochure.

  5. 05 Grid Mode

    Build with rows instead

    In Grid Mode every row is a container. Content blocks sit inside its columns and stack neatly, top to bottom.

  6. 06 Grid Mode

    Set columns and widths

    Choose how many columns each row needs and drag their widths. Structured, repeatable and easy to maintain.
